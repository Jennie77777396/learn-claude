# Claude / Anthropic Websites

A quick guide to the four main official sites and what each is for.

## `anthropic.com`

The company website. Anthropic is the AI lab that builds Claude. Used for:
- Research papers
- Blog posts and news
- Policy and safety publications
- Careers
- Enterprise sales pages

Not where you do work — it's "about the company."

## `claude.ai`

The consumer chat product. End-users sign in here to chat with Claude. Includes:
- Free / Pro / Max / Team / Enterprise plans
- Projects and conversations
- File uploads
- Claude Skills
- The web version of Claude Code

## `platform.claude.com`

The developer platform / console. Used by developers building on the Claude API. Includes:
- API keys
- Organization management
- Billing and usage
- Workspaces
- API playground

This is the newer home of what used to be `console.anthropic.com`.

## `code.claude.com`

The Claude Code product site. Hosts:
- Official Claude Code documentation (`code.claude.com/docs/en/...`)
- Download / install instructions
- Release notes

This is the source for the canonical docs URLs referenced throughout the other files in this folder.
