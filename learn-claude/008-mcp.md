# MCP (Model Context Protocol) Configuration

A reference for configuring MCP servers in Claude Code.

## Configuration Scopes

| Scope | Loads In | Shared | File Path | Priority |
|---|---|---|---|---|
| **Local** | Current project only | No (private) | `~/.claude.json` (project-keyed) | 1 (highest) |
| **Project** | Current project only | Yes (version control) | `.mcp.json` (repo root) | 2 |
| **User** | All your projects | No (private) | `~/.claude.json` (global) | 3 |
| **Plugin** | Where plugin enabled | Via plugin install | Plugin root `.mcp.json` | 4 |
| **Claude.ai** | All projects | Org-managed | Remote (claude.ai account) | 5 (lowest) |

**Precedence:** Local > Project > User > Plugin > Claude.ai connector (first match by name/URL).

### Managed (enterprise) config paths

- **macOS:** `/Library/Application Support/ClaudeCode/managed-mcp.json`
- **Linux/WSL:** `/etc/claude-code/managed-mcp.json`
- **Windows:** `C:\Program Files\ClaudeCode\managed-mcp.json`

## Transport Types

### HTTP (recommended)

```json
{
  "mcpServers": {
    "sentry": {
      "type": "http",
      "url": "https://mcp.sentry.dev/mcp",
      "headers": {
        "Authorization": "Bearer token-here"
      }
    }
  }
}
```

Alias: `streamable-http` (both accepted).

### SSE (deprecated — prefer HTTP)

```json
{
  "mcpServers": {
    "asana": {
      "type": "sse",
      "url": "https://mcp.asana.com/sse",
      "headers": {
        "X-API-Key": "api-key-here"
      }
    }
  }
}
```

### Stdio (local process)

```json
{
  "mcpServers": {
    "airtable": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "airtable-mcp-server"],
      "env": {
        "AIRTABLE_API_KEY": "key-here"
      }
    }
  }
}
```

Stdio servers receive `CLAUDE_PROJECT_DIR` in their environment.

## `mcpServers` Object Schema

### Shared fields (all transports)

| Field | Type | Description |
|---|---|---|
| `type` | `"http"` \| `"sse"` \| `"stdio"` | Transport mechanism |
| `alwaysLoad` | boolean | Load tools into context at startup (blocks 5s timeout); overrides tool-search deferral |
| `instructions` | string | Describes server's task category — helps tool search. Truncated at 2KB |

### HTTP / SSE fields

| Field | Type | Description |
|---|---|---|
| `url` | string | Server endpoint; supports `${VAR}` / `${VAR:-default}` |
| `headers` | object | Static HTTP headers; supports `${VAR}` expansion |
| `headersHelper` | string | Command that generates dynamic headers at connection time. Receives `CLAUDE_CODE_MCP_SERVER_NAME` and `CLAUDE_CODE_MCP_SERVER_URL`. 10s timeout, must output JSON |
| `oauth` | object | OAuth 2.0 configuration (see below) |

### Stdio fields

| Field | Type | Description |
|---|---|---|
| `command` | string | Executable path; supports `${VAR}` expansion |
| `args` | string[] | Command arguments; supports `${VAR}` expansion |
| `env` | object | Environment variables for spawned process; supports `${VAR}` |

### OAuth object

| Field | Type | Description |
|---|---|---|
| `clientId` | string | OAuth 2.0 client ID (omit to enable dynamic client registration) |
| `callbackPort` | number | Localhost port for OAuth redirect |
| `authServerMetadataUrl` | string | Override discovery (RFC 8414 metadata URL) |
| `scopes` | string | Space-separated OAuth scopes |

Client secrets are stored in the system keychain (macOS) or credentials file — never in config.

## CLI Commands

### Add servers

```bash
# HTTP (recommended)
claude mcp add --transport http <name> <url> \
  [--header "Key: value"] \
  [--scope local|project|user] \
  [--callback-port 8080] \
  [--client-id ID] [--client-secret]

# SSE (deprecated)
claude mcp add --transport sse <name> <url> [--header "Key: value"] [--scope local|project|user]

# Stdio
claude mcp add [--transport stdio] [--env VAR=value] [--scope local|project|user] <name> -- <command> [args...]

# From JSON
claude mcp add-json <name> '<json-config>' [--scope local|project|user] [--client-secret]

# Import from Claude Desktop
claude mcp add-from-claude-desktop [--scope user]
```

**Important:** Options come **before** the server name; `--` separates options from the stdio command.

### Manage servers

```bash
claude mcp list                       # list all configured servers
claude mcp get <name>                 # show one server's details
claude mcp remove <name>              # remove a server
claude mcp reset-project-choices      # reset .mcp.json approval dialogs
claude mcp serve                      # expose Claude Code as an MCP server
```

### In-session `/mcp` command

Shows connected servers, tool counts, and authentication status. Initiates OAuth sign-in for servers needing authentication.

## Environment Variable Expansion

Syntax in `.mcp.json`:
- `${VAR}` — required env var
- `${VAR:-default}` — use `VAR` if set, else `default`

Supported in: `command`, `args`, `env`, `url`, `headers`.

Special: `${CLAUDE_PROJECT_DIR}` is available to stdio servers; in `.mcp.json` use `${CLAUDE_PROJECT_DIR:-.}` for safety.

```json
{
  "mcpServers": {
    "api": {
      "type": "http",
      "url": "${API_BASE_URL:-https://api.example.com}/mcp",
      "headers": {
        "Authorization": "Bearer ${API_KEY}"
      }
    }
  }
}
```

## Project Trust (`.mcp.json`)

- First use of project-scoped servers prompts a **one-time approval dialog** ("Do you trust this project?").
- Applies to `command` (stdio) and `headersHelper` execution.
- Reset with `claude mcp reset-project-choices`.

**Auto-approval settings** (in `settings.json`):

| Setting | Behavior |
|---|---|
| `enableAllProjectMcpServers` | Auto-approve all `.mcp.json` servers |
| `enabledMcpjsonServers` | Approve specific `.mcp.json` servers by name |
| `disabledMcpjsonServers` | Reject specific `.mcp.json` servers by name |

## Permissions Integration

MCP tools appear in permission rules as `mcp__<server>__<tool>`:

```json
{
  "permissions": {
    "allow": [
      "Bash(mcp__github__*)",
      "Read(mcp__*)"
    ],
    "deny": [
      "Bash(mcp__dangerous-server__*)"
    ]
  }
}
```

### Managed allowlist / denylist

```json
{
  "allowedMcpServers": [
    { "serverName": "github" },
    { "serverUrl": "https://mcp.company.com/*" },
    { "serverCommand": ["npx", "-y", "approved-tool"] }
  ],
  "deniedMcpServers": [
    { "serverUrl": "https://*.untrusted.com/*" }
  ]
}
```

Match keys:
- `serverName` — exact match by configured name
- `serverCommand` — exact array match (stdio only)
- `serverUrl` — wildcard pattern (HTTP/SSE; `*` matches any sequence)

Hostname matching is case-insensitive and ignores trailing FQDN dot. Denylist takes precedence.

Other settings:
- `ENABLE_CLAUDEAI_MCP_SERVERS=false` disables claude.ai connectors.

## Authentication

### OAuth flow (hosted MCP servers)

1. Add server: `claude mcp add --transport http <name> <url>`
2. On `401`/`403`, Claude Code flags it in `/mcp`.
3. Run `/mcp` → browser login.
4. Token stored securely; auto-refreshed.

Hosted MCP servers typically expose `authenticate` / `complete_authentication` tools to drive the flow.

### Dynamic headers (custom auth)

For Kerberos, short-lived tokens, or internal SSO:

```json
{
  "mcpServers": {
    "internal": {
      "type": "http",
      "url": "https://internal.example.com",
      "headersHelper": "/usr/local/bin/generate-auth-headers.sh"
    }
  }
}
```

`headersHelper` output must be a JSON object (e.g. `{"Authorization": "Bearer ..."}`). 10s timeout.

## Resources & Prompts

### Resource references

Type `@` in prompt; MCP resources appear alongside files:

```
Can you analyze @github:issue://123 and suggest a fix?
Compare @postgres:schema://users with @docs:file://api/schema
```

Format: `@<server>:<protocol>://<path>`

### MCP prompts as slash commands

Type `/` to list. MCP prompts appear as:

```
/mcp__<servername>__<promptname> [args...]
```

Examples:

```
/mcp__github__pr_review 456
/mcp__jira__create_issue "Bug in login" high
```

## Tool Search & Loading

MCP tools are deferred by default and loaded on demand (low context overhead). Controlled by `ENABLE_TOOL_SEARCH`:

| Value | Behavior |
|---|---|
| (unset) | All tools deferred, loaded on demand (default) |
| `true` | Force deferral; fails on Haiku / proxies without `tool_reference` |
| `auto` | Load upfront if <10% of context, defer overflow |
| `auto:N` | Custom threshold (N = 0–100; e.g. `auto:5` = 5%) |
| `false` | Load all tools upfront at startup |

Per-server override: set `alwaysLoad: true` on the server.

Requires Claude Sonnet 4+ or Opus 4+ (models with `tool_reference` support).

## Output Limits

| Limit | Value |
|---|---|
| Warning threshold | 10,000 tokens |
| Soft limit | 25,000 tokens (configurable via `MAX_MCP_OUTPUT_TOKENS`) |
| Per-tool override | `_meta["anthropic/maxResultSizeChars"]` on the tool's `tools/list` entry, up to 500KB |

Increase: `MAX_MCP_OUTPUT_TOKENS=50000 claude`

## Managed Configuration Strategies

### Exclusive control (`managed-mcp.json`)

Users cannot add/modify servers; only those listed are available.

```json
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/"
    },
    "internal": {
      "type": "stdio",
      "command": "/usr/bin/internal-mcp",
      "args": ["--config", "/etc/mcp.conf"],
      "env": { "API_URL": "https://internal.company.com" }
    }
  }
}
```

### Policy-based (allowlist/denylist in managed settings)

Users may add servers, but only those passing the allowlist are usable.

## Common Recipes

| Scenario | Command / Config |
|---|---|
| Add GitHub with PAT | `claude mcp add --transport http github https://api.githubcopilot.com/mcp/ --header "Authorization: Bearer TOKEN"` |
| PostgreSQL stdio | `claude mcp add --transport stdio db -- npx -y @bytebase/dbhub --dsn "postgresql://..."` |
| Authorize in session | `/mcp` |
| View server details | `claude mcp get <name>` |
| List all servers | `claude mcp list` |
| Disable claude.ai servers | `ENABLE_CLAUDEAI_MCP_SERVERS=false claude` |
| Fix OAuth port | `--callback-port 8080` with `--client-id` |
| Env var in config | `${VAR:-default}` in command/args/env/url/headers |
| Team-shared setup | Commit `.mcp.json` to repo; first use prompts approval |

## Full Example

```json
{
  "mcpServers": {
    "github": {
      "type": "http",
      "url": "https://api.githubcopilot.com/mcp/",
      "headers": {
        "Authorization": "Bearer ${GITHUB_PAT}"
      },
      "alwaysLoad": false
    },
    "internal-api": {
      "type": "http",
      "url": "https://api.internal.company.com/mcp",
      "headersHelper": "/opt/bin/get-auth-headers.sh",
      "oauth": {
        "authServerMetadataUrl": "https://auth.company.com/.well-known/openid-configuration",
        "scopes": "api:read api:write"
      }
    },
    "local-db": {
      "type": "stdio",
      "command": "python3",
      "args": ["${CLAUDE_PROJECT_DIR:-.}/server.py"],
      "env": {
        "DB_HOST": "${DB_HOST:-localhost}",
        "DB_PORT": "${DB_PORT:-5432}"
      }
    }
  }
}
```
