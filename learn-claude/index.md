# learn-claude

A reference set for learning Claude Code. Files are numbered in suggested reading order — orientation first, then daily use, then customization.

## Essentials

1. [001-claude-website.md](001-claude-website.md) — The four official Claude / Anthropic sites and what each is for
2. [002-slash-command.md](002-slash-command.md) — Built-in slash commands grouped by category
3. [003-settings.md](003-settings.md) — `settings.json` reference: every configuration key, file precedence, examples
4. [004-memory.md](004-memory.md) — How auto memory works: storage, the four memory types, when to save/access

## Extensions

5. [005-skills.md](005-skills.md) — Creating custom skills: `SKILL.md` frontmatter, bundled resources, visibility
6. [006-sub-agents.md](006-sub-agents.md) — Built-in agent types, when to use each, prompt-writing tips

## Advanced

7. [007-hooks.md](007-hooks.md) — All hook events, matchers, output schemas, configuration shape
8. [008-mcp.md](008-mcp.md) — MCP server configuration: scopes, transports, OAuth, permissions

---

All files reference the official Claude Code docs at https://code.claude.com/docs/en/ — each file ends with a direct link to the canonical page.
